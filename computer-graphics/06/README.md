# Практическая работа №6. Отсечение многоугольников (Сазерленд–Ходжман)

## 1. Способ задания многоугольника
Многоугольник задается двумя способами:
1. Кликами мыши по логической сетке (вершины соединяются в порядке клика).
2. Кнопкой «Загрузить тестовый», которая вставляет заранее подготовленный невыпуклый многоугольник.

## 2. Параметры окна
Окно отсечения задается полями `xmin`, `ymin`, `xmax`, `ymax`. 
По умолчанию: `xmin=10, ymin=8, xmax=30, ymax=22`.
Программа проверяет условие `xmin < xmax` и `ymin < ymax`.

## 3. Таблица четырёх переходов
| Предыдущая точка (S) | Текущая точка (P) | Что добавляется в результат |
| :--- | :--- | :--- |
| Inside | Inside | Только точка P |
| Inside | Outside | Только точка пересечения |
| Outside | Inside | Точка пересечения и точка P |
| Outside | Outside | Ничего не добавляется |

## 4. Формулы пересечения
- **С вертикальной границей (x = const):**
  `t = (xBoundary - a.x) / (b.x - a.x)`
  `y = a.y + t * (b.y - a.y)`
- **С горизонтальной границей (y = const):**
  `t = (yBoundary - a.y) / (b.y - a.y)`
  `x = a.x + t * (b.x - a.x)`

## 5. Промежуточные списки вершин (тест)
Если загрузить встроенный тестовый невыпуклый многоугольник и нажать «Замкнуть контур», в таблице под canvas отобразятся результаты по шагам:
- **Исходный:** 6 вершин.
- **После LEFT:** отсекается левая часть.
- **После RIGHT:** отсекается правая часть.
- **После TOP:** отсекается верхняя часть.
- **После BOTTOM:** остается финальная видимая область.

## 6. Один ручной расчёт (Пример)
Рассмотрим отсечение по левой границе (`x = 10`).
Ребро: от `S(5, 15)` (снаружи) до `P(15, 5)` (внутри).
- Переход: **Outside → Inside** (добавляем пересечение и P).
- Вычисляем `t`:
  `t = (10 - 5) / (15 - 5) = 5 / 10 = 0.5`
- Вычисляем `y`:
  `y = 15 + 0.5 * (5 - 15) = 15 - 5 = 10`
- Точка пересечения: `(10, 10)`.
В выходной массив добавятся: `(10, 10)` и `P(15, 5)`.

## 7. Результаты обязательных тестов
1. **Полностью внутри:** Алгоритм возвращает исходный многоугольник без изменений.
2. **Полностью снаружи:** На первом же этапе список вершин становится пустым `[]`.
3. **Пересекает одну / две / все четыре границы:** Алгоритм формирует новые вершины, замыкая контур точно по границам окна.
4. **Вершина лежит на границе:** Условие `inside` включает равенство (`>=` или `<=`), поэтому точка считается внутри.
5. **Ребро идёт вдоль границы:** Обе точки внутри, ребро сохраняется.
6. **Невыпуклый многоугольник:** Обрабатывается корректно, алгоритм Сазерленда-Ходжмана работает для любого многоугольника, если окно выпуклое (прямоугольник).
7. **Пустой результат:** Если фигура полностью отсеклась, в таблице напротив этапа будет `0` вершин и `—`.
