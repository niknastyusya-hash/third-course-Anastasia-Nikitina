# Практическая работа №5. Заполнение областей (Flood Fill и Scanline)

## 1. Как запустить работу
1. Откройте файл `index.html` в любом современном браузере (рекомендуется использовать расширение Live Server в VS Code).
2. **Построение контура:** Кликайте левой кнопкой мыши по клеткам сетки, чтобы расставить вершины многоугольника. Сделайте фигуру невыпуклой (например, в форме звезды или буквы "С"), чтобы наглядно увидеть разницу в работе алгоритмов.
3. Нажмите кнопку **«Замкнуть контур»**. Стороны фигуры будут построены с помощью алгоритма Брезенхема.
4. **Тестирование Flood Fill:** Кликните мышкой внутрь замкнутой области. Заливка начнется от этой точки. Появится ползунок, с помощью которого можно пошагово проследить, как заливка распространяется по сетке.
5. **Тестирование Scanline Fill:** Нажмите кнопку «Scanline Fill». Фигура закрасится построчно, а в нижней таблице отобразится расчет пересечений для каждой строки.
6. **Сравнение методов:** Нажмите зеленую кнопку «Запустить сравнение», чтобы увидеть результаты замеров скорости и количества обработанных пикселей.

## 2. Как задаётся многоугольник
Многоугольник формируется динамически. Координаты вершин хранятся в массиве объектов `vertices` (например, `[{x: 10, y: 5}, {x: 20, y: 15}, ...]`).
Когда контур замыкается, программа проходит по всем парам соседних вершин и соединяет их линиями с помощью алгоритма Брезенхема. Эти линии записываются в логический растр как границы.

## 3. Как хранится логический растр
Весь рисунок хранится в двумерном массиве `grid` размером 40x30 (каждый элемент — это логический пиксель). Canvas используется исключительно как «монитор» для отрисовки этого массива, а не как хранилище данных. 
Каждая клетка массива может иметь одно из значений:
- `0` (EMPTY) — пустая клетка;
- `1` (BORDER) — граница (контур);
- `2` (FILL) — закрашенная область;
- `3` (CURRENT_STEP) — текущий пиксель в пошаговом режиме.

## 4. Вариант связности
В алгоритме **Flood Fill используется 4-связность**. Это означает, что алгоритм проверяет только четырех соседей пикселя (сверху, снизу, слева, справа). Диагонали не учитываются, чтобы заливка не могла «протечь» через узкие диагональные щели в контуре.

## 5. Правило обработки вершин в Scanline
При проведении сканирующей строки возникает проблема: если вершина принадлежит двум ребрам, точка пересечения может посчитаться дважды. 
Чтобы этого избежать, используется правило: **нижняя граница включается, а верхняя — нет** (`yMin <= y < yMax`).
Также **горизонтальные ребра полностью игнорируются** при поиске пересечений, так как они не меняют четность/нечетность пересечений.

## 6. Результаты обязательных тестов
В ходе проверки работы программы были получены следующие результаты:
1. **Прямоугольник / Треугольник:** закрашиваются корректно и без «дыр» с помощью обоих методов.
2. **Выпуклый (5+ вершин) и невыпуклый многоугольники:** Scanline Fill успешно справляется с невыпуклыми фигурами, разбивая одну строку на несколько закрашиваемых интервалов.
3. **Горизонтальное ребро:** в Scanline игнорируется, заполнение происходит корректно.
4. **Сканирующая строка проходит через вершину:** благодаря правилу `y < max(y1, y2)` вершина учитывается только один раз, заливка не прерывается.
5. **Flood Fill внутри:** закрашивает ровно ту область, которая ограничена контуром.
6. **Flood Fill снаружи:** закрашивает всё внешнее пространство, оставляя фигуру пустой.
7. **Незамкнутый контур:** если оставить разрыв в границе, алгоритм Flood Fill «протекает» через него и заливает весь экран. Алгоритм не понимает геометрию, он просто ищет пустые соседние пиксели.

## 7. Сравнение методов
Для одного и того же многоугольника встроенная функция замеряет время выполнения серии запусков (50 раз), а также считает количество закрашенных пикселей.

| Метод | Нужна стартовая точка (seed) | Использует список вершин | Что обходится | Скорость |
| :--- | :--- | :--- | :--- | :--- |
| **Flood Fill** | Да (клик мыши) | Нет | Соседние пиксели (через очередь) | Зависит от площади |
| **Scanline** | Нет | Да | Строки и рёбра многоугольника | Высокая, зависит от периметра |

### Ответы на вопросы из задания:
- **Когда нужен seed?** Seed (стартовая точка) нужен только для Flood Fill, так как этот алгоритм понятия не имеет о геометрии фигуры — ему нужно знать, откуда начинать поиск связной области.
- **Какой метод использует геометрию многоугольника?** Scanline Fill. Он анализирует координаты вершин, находит математические пересечения ребер со строкой и закрашивает интервалы между ними.
- **Что произойдёт при разрыве контура?** Flood Fill протечет через дырку и зальет всё вокруг, так как для него нет разницы между «внутри» и «снаружи» — он ищет пустые пиксели. Scanline в этом случае может закрасить лишнее (в зависимости от направления обхода вершин), но чаще всего он закрасит пространство так, будто контур замкнут напрямую.
- **Почему результаты на границе зависят от правила округления?** Пересечения строк с ребрами дают дробные координаты (например, `x = 5.3`). Чтобы закрасить логический пиксель, нужно округлить значение. Мы используем `Math.ceil` для левой границы (чтобы не вылезти за ребро) и `Math.floor` для правой. Разные правила округления могут сдвигать границу закрашенной области на 1 пиксель влево или вправо.
