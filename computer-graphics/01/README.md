# Занятие 1. Растровая графика, пиксели и алгоритм ЦДА

Реализация алгоритма ЦДА (цифрового дифференциального анализатора)
для растеризации отрезка на Canvas без использования `ctx.lineTo()`.

## Файлы

- `index.html` — структура страницы: форма, canvas, таблица шагов;
- `style.css` — внешний вид;
- `app.js` — алгоритм ЦДА, вывод пикселей, построение таблицы.

## Ответы на вопросы

**Что такое растеризация?**

Растеризация — это процесс преобразования геометрического объекта в набор пикселей растра.
Математический объект непрерывен, а экран дискретен: пиксель либо есть,
либо нет. Задача растеризации — выбрать, какие именно клетки растра
изображают объект наиболее точно.

**Зачем в ЦДА выбирается max(|dx|, |dy|)?**

Это количество шагов. Берётся «длинная» сторона, чтобы на каждый шаг
приходилось не больше одной клетки по обеим осям. Если взять меньше
(например, min), то по длинной стороне за один шаг будет пройдено
несколько клеток, и в линии появятся разрывы. Если взять больше —
алгоритм будет работать вхолостую, ставя по нескольку раз один и тот же
пиксель.

**Почему координаты приходится округлять?**

ЦДА работает с вещественными числами: на каждом шаге x и y увеличиваются
на дробные приращения (например, 0.5). Но пиксель имеет целочисленные
координаты. Чтобы выбрать конкретную клетку растра, приходится округлять
текущее значение до ближайшего целого (`Math.round`).

**Что произойдёт, если начало и конец отрезка совпадают?**

dx = 0, dy = 0, steps = 0. Деление на steps привело бы к ошибке
(деление на ноль). Поэтому в коде есть отдельная ветка: если steps === 0,
мы просто ставим одну точку и выходим из функции.

**Какие недостатки ЦДА вы заметили?**

- Использует вещественные числа — работает медленнее целочисленных алгоритмов.
- На каждом шаге выполняется деление (для вычисления xStep и yStep).
- Требуется округление на каждом шаге.
- Может накапливать погрешность из-за сложения вещественных чисел.
