# Занятие 2. Анализатор чисел

Приложение, в котором пользователь добавляет числа в список, а интерфейс
автоматически показывает количество, сумму, среднее, минимум и максимум.

## Файлы

- `index.html` — структура: форма ввода, список, таблица показателей;
- `style.css` — внешний вид;
- `app.js` — состояние, чистые функции, функция отображения, обработчики.

## Ответы на вопросы

**Где хранятся исходные данные?**

Все исходные данные хранятся в одном массиве `values` в файле `app.js`.
Больше нигде список чисел не дублируется — ни в DOM, ни в отдельных
переменных. Показатели (сумма, среднее, минимум, максимум) тоже
не хранятся отдельно: они каждый раз вычисляются из массива функцией
`getStatistics()`.

**Почему показатели лучше вычислять из массива, а не хранить отдельно?**

Если хранить, например, `sum` и `count` отдельно, их придётся обновлять
в каждом обработчике: при добавлении прибавлять, при удалении вычитать,
при очистке сбрасывать. Любая ошибка или пропущенный вызов приведут
к расхождению между массивом и показателями. А если вычислять из массива
функцией `getStatistics()`, данные и их производные всегда согласованы —
показатели не могут «отстать» от массива.

**Что возвращает getStatistics()?**

Функция `getStatistics()` принимает массив чисел и возвращает объект
с полями:

- `count` — количество элементов;
- `sum` — сумма;
- `min` — минимальное значение;
- `max` — максимальное значение;
- `average` — среднее арифметическое.

**Как программа обрабатывает пустой массив?**

Функция `getStatistics()` в самом начале проверяет `arr.length === 0`
и сразу возвращает объект с `null` в полях `sum`, `min`, `max`, `average`.
Это нужно, чтобы не получать `NaN` или `Infinity` от деления на ноль.
В функции `render()` значение `null` заменяется на прочерк `—`, и
пользователь видит аккуратный интерфейс вместо «мусорных» чисел.

**Какое место в программе было сложнее всего отладить?**

Сложнее всего было понять, почему при пустом массиве среднее значение
выводилось как `NaN`. Причина в том, что деление `0 / 0` даёт `NaN`,
а `NaN` превращается в строку «NaN» при записи в `textContent`.
Решение — отдельная ветка для пустого массива с возвратом `null`
и замена `null` на прочерк при отображении.
