# Лабораторная работа №3. Каталог пользователей из API

Приложение получает список пользователей с публичного API JSONPlaceholder,
показывает их карточками, позволяет фильтровать по имени, username и email,
выводит статистику.

## Файлы

- `index.html` — структура: кнопки, поиск, список, статистика;
- `style.css` — внешний вид;
- `app.js` — состояние, сетевой запрос, фильтрация, рендер.

## Ответы на вопросы

**Какой endpoint используется?**

`https://jsonplaceholder.typicode.com/users` — публичный тестовый API,
возвращает массив из 10 пользователей в формате JSON.

**Какой HTTP-метод отправляется?**

`GET`. Метод по умолчанию для `fetch(url)`. Читаем данные, ничего не
создаём и не изменяем на сервере.

**Где в программе хранится состояние?**

Состояние — один объект `state` в `app.js`:

- `state.users` — массив пользователей, полученный с сервера;
- `state.isLoading` — идёт ли сейчас загрузка;
- `state.error` — текст ошибки или `null`;
- `state.filter` — текущая строка поиска.

DOM ничего не хранит: все данные и флаги живут в `state`, а `render()`
лишь отображает то, что там лежит.

**Какие состояния интерфейса предусмотрены?**

- **Данные ещё не загружены** — статус «Данные ещё не загружены.».
- **Загрузка** — статус «Загрузка...» (синим), кнопки отключены.
- **Успех** — карточки пользователей, статистика.
- **Ошибка** — красное сообщение с текстом проблемы.

**Как обрабатывается ошибка?**

Сетевой запрос обёрнут в `try/catch`. Внутри проверяется `response.ok`.
Если ответ не 2xx — генерируется исключение с кодом состояния. Оно
перехватывается в `catch`, текст ошибки сохраняется в `state.error`.
В `finally` флаг `isLoading` сбрасывается в любом случае, и вызывается
`render()`. Благодаря `finally` интерфейс не зависает в состоянии
«Загрузка...».

**Какие поля участвуют в фильтрации?**

- `user.name`
- `user.username`
- `user.email`

Сравнение — через `toLowerCase().includes(query)`. Регистр не важен,
строка ищется как подстрока. Достаточно совпадения по любому из трёх
полей.

**Что вы увидели в Network при успешном запросе и при ошибке?**

**Успешный запрос:**

- Request URL: `https://jsonplaceholder.typicode.com/users`
- Request Method: `GET`
- Status Code: `200 OK`
- Content-Type: `application/json; charset=utf-8`
- Response: JSON-массив из 10 объектов с полями `id`, `name`,
  `username`, `email`, `address`, `phone`, `website`, `company`.

**Запрос с ошибкой** (проверяла с заведомо неправильным адресом
`.../users-wrong`):

- Status Code: `404 Not Found`
- Приложение показало статус «Не удалось загрузить данные:
  HTTP error: 404».
- Кнопки разблокировались, поле поиска не зависло.
