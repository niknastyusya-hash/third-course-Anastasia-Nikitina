# Занятие 1. Счётчик

Небольшое веб-приложение: числовое значение и три кнопки — `+1`, `−1`, `Сброс`.
Под числом выводится сообщение о том, положительное оно, отрицательное или равно нулю.

## Файлы

- `index.html` — структура страницы;
- `style.css` — внешний вид;
- `app.js` — поведение (логика счётчика).

## Ответы на вопросы

**Где в программе хранится состояние?**

Состояние хранится в одной переменной `value` в файле `app.js`.
Она объявлена как `let value = 0;` и изменяется только в обработчиках кнопок.
DOM не хранит состояние — он лишь отображает текущее значение `value`.

**Какая функция обновляет интерфейс?**

Интерфейс обновляет функция `render()`.
Она читает текущее значение переменной `value` и записывает его в элементы
страницы (`#value` и `#status`). Вызывается после каждого изменения `value`
и один раз при загрузке страницы.

**Какие события обрабатываются?**

Обрабатывается событие `click` на трёх кнопках:

- `#increase` — увеличивает `value` на 1;
- `#decrease` — уменьшает `value` на 1;
- `#reset` — сбрасывает `value` в 0.

**Что произойдёт, если изменить значение переменной, но не вызвать функцию обновления интерфейса?**

Ничего не изменится на экране. Переменная `value` — это обычное число в памяти
JavaScript, а DOM о нём ничего не знает. Пока `render()` не перезапишет текстовое
содержимое элементов `#value` и `#status`, пользователь будет видеть старое значение.
Поэтому в коде каждое изменение `value` сопровождается вызовом `render()`.
